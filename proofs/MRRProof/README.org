#+title: MRR Proof Validation
#+options: toc:nil

The Python package =src/mrr_proof_validation= owns native Gerbil test
qualification, Context checks, source proof evidence, and TLA+ receipts.
Tests and fixtures live in =tests/= and =fixtures/=. The repository
=justfile= and CI call package modules directly.

Run the focused Python checks from the repository root through the captured
development environment:

#+begin_src sh
./.devenv/devenv-profile-exec env PYTHONPATH=proofs/MRRProof/src python3 -m pytest -q proofs/MRRProof/tests
#+end_src

The package exposes CLI entry points in =pyproject.toml=. The =context-tla=
just recipe checks the revision model against Lean replay; =meta-impact=
checks the finite Meta Impact model and required counterexamples. These are
bounded model checks, not source refinement or deployed behavior evidence.
The neighboring proof projects state each gate's assumptions and receipts.
