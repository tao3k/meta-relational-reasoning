* Status

Accepted target contract. This RFC does not claim that the target is already
implemented or that the repository is ISO certified.

* Normative evidence

The language baseline is ISO/IEC 39075:2024. ISO/IEC 39075:2024/Cor 1:2026 is
a published versioned correction at ISO stage 60.60. Public product metadata
proves that publication lifecycle fact only. Feature correction and completion
still require licensed clause text, a feature mapping, and positive and
negative executable evidence. ISO committee drafts are future-delta inputs and
do not silently change the default language.

SeleneDB, Grafeo, and froGQL remain differential oracles and literature
references. They are neither normative evidence nor production dependencies.

* Profile ownership

=scheme/grammar/gql-profile.ss= is the sole machine-readable release, module,
profile, feature, dependency, layer-status, and evidence-owner declaration.
It is checked by Gerbil =syntax-case= and loaded through the native AOT ABI as
the typed, read-only =mrr_gerbil::load_iso_profile= API. It is deliberately not
copied into unused =gql-syntax= constants. Test fixtures stay with their Rust
owner; this RFC explains and audits the contract but does not duplicate
executable data. The removed YAML ledger is not a compatibility input.

=gql-query-language-frontend-v1= remains the selected implementation claim.
=gql-iso-language-frontend-v1= is the complete language-frontend target and
contains every inventoried module with no deferred module. Moving the selected
profile to that target requires every feature to cross the evidence gates; a
profile name alone cannot widen implementation status.

= RFC 0024: ISO GQL Language Frontend Admission

Let $M$ be the set of all inventoried ISO language modules and $F(m)$ the
features owned by module $m$. The target profile satisfies

$ "Included"("target") = M quad and quad "Deferred"("target") = emptyset. $

A feature $f in F(m)$ is admitted as complete only when

$ "Clause"(f) and "CST"(f) and "AST"(f) and "Sema"(f)
  and "IR"(f) and "Positive"(f) and "Negative"(f). $

Publication metadata and oracle agreement cannot substitute for
$"Clause"(f)$. Until all target features are admitted, the selected profile
remains narrower than the target profile.

For a node pattern $n = (b, L, P, w)$ with binding $b$, ordered labels $L$,
ordered property constraints $P$, and optional inline predicate $w$, canonical
lowering is the partial function

$ "LowerNode"(n, Gamma) = ("canon"(b), "map"("canon", L),
  "LowerProps"(P, Gamma), "LowerExpr"(w, Gamma)). $

It is admitted only when every name in $w$ resolves in the same query binding
environment $Gamma$; syntax failure or semantic failure yields no query IR.

For an edge pattern $e = (d, b, L, P, w, q)$, direction $d$ and quantifier
$q$ are retained while the edge-local predicate uses that same environment:

$ "LowerEdge"(e, Gamma) = (d, "canon"(b), "map"("canon", L),
  "LowerProps"(P, Gamma), "LowerExpr"(w, Gamma), q). $

An absent predicate is distinct from a malformed predicate. The latter is a
typed rejection and cannot be represented by an empty expression.

For a label predicate $x " IS " nu " LABELED :" ell$, where
$nu in {epsilon, "NOT"}$, label algebra is

$ ell ::= a mid "%" mid "!" ell mid ell "&" ell mid ell "|" ell, $

with binding power $"!" > "&" > "|"$. Canonical lowering preserves that
tree exactly:

$ "LowerLabel"(a) = "Name"("canon"(a)), quad
  "LowerLabel"("%") = "Wildcard", $
$ "LowerLabel"("!" ell) = "Not"("LowerLabel"(ell)), $
$ "LowerLabel"(ell_1 "&" ell_2) =
  "And"("LowerLabel"(ell_1), "LowerLabel"(ell_2)), $
$ "LowerLabel"(ell_1 "|" ell_2) =
  "Or"("LowerLabel"(ell_1), "LowerLabel"(ell_2)). $

The predicate is defined only for graph-element operands. A malformed algebra
or a non-graph operand produces one typed diagnostic and no query IR.

Let $mu in {"Walk", "Trail", "Acyclic", "Simple"}$ be the path mode owned by
a MATCH clause and let $G = (g_1, ..., g_n)$ be its non-empty, source-ordered
graph-pattern list. Canonical admission preserves every component and applies
the mode exactly:

$ "LowerMatch"(mu, G, Gamma) =
  ("LowerGraph"(g_i, mu, Gamma))_(i = 1)^n, quad n >= 1. $

For successive MATCH clauses $M_1, ..., M_k$, the query-block graph sequence is
their ordered concatenation. Reusing a binding with the same graph-element kind
is a join identity; reusing it with a different kind makes lowering undefined.

An OPTIONAL MATCH operation $O = (mu, G, w)$ is one atomic null-preserving
group, including every component in $G$ and its directly associated predicate
$w$:

$ "LowerOptional"(O, Gamma) =
  "LeftOuter"("LowerMatch"(mu, G, Gamma), "LowerExpr"(w, Gamma union "Bind"(G))). $

The operation is valid with an empty incoming mandatory graph sequence. Its
predicate is not interchangeable with an outer query filter. Static nullable
result typing remains a separate admission obligation.

When the modifier is absent, the grammar-defined value is $"Walk"$; when a
modifier is present without a graph pattern, lowering is undefined and the
frontend emits one typed diagnostic rather than constructing an empty graph.

For quantified edge spelling $q$, the canonical bound pair is

$ "Bounds"(q) = cases(
  (0, "none"), q = "*",
  (1, "none"), q = "+",
  (0, 1), q = "?",
  (n, n), q = "{n}",
  (n, "none"), q = "{n,}",
  (0, m), q = "{,m}",
  (n, m), q = "{n,m}"
). $

Admission requires at least one bound and, when both are present, $n <= m$.

For the admitted operator slice, Gerbil owns the strict binding-power order

$ "OR" < "XOR" < "AND" < "NOT" < "comparison" < "||"
  < "+,-" < "*,/,%" < "unary +,-". $

Keyword operators have token width one regardless of lexeme length; only
multi-character punctuation such as $"<>"$ and $"||"$ has width two. Typed
lowering is partial:

$ "LowerOp"(o, x, y) = cases(
  "boolean", o in {"OR", "XOR", "AND"} and x,y in "Boolean",
  "string", o = "||" and x,y in "String",
  "numeric", o in {"+", "-", "*", "/", "%"} and x,y in "Numeric",
  bot, "otherwise"
). $

For source $s$, the frontend publication boundary is

$ "Compile"(s) = cases(
  ("some"(a), emptyset, "some"(i)), "when parsing, lowering, and semantics admit",
  ("none", D, "none"), "when parsing or lowering rejects",
  ("some"(a), D, "none"), "when semantics rejects"
). $

There is no fourth branch containing a fabricated AST, default IR, legacy
parser result, or compatibility shim.
#+end_src

* Unicode identifier boundary

Unicode is the character repertoire, not a synonym for Chinese text.  The
OpenGQL grammar now provides the exact lexical productions used by this slice:
=IDENTIFIER_START = ID_Start | Pc= and =IDENTIFIER_EXTEND = ID_Continue=.
The lexer queries ICU4X compiled property data directly; it does not substitute
Rust alphabetic predicates or UAX #31 =XID_*= categories.  The lookup tables are
static borrowed data, so there is no Runtime initialization, allocation, or
backend authority on the token hot path.

The Gerbil declaration owns all 47 =nonReservedWords= and projects them through
the native AOT ABI into an allocation-free Rust classifier.  A
=regularIdentifier= is either an undelimited Unicode identifier or one of those
47 words.  An =identifier= additionally admits double-quoted or grave-accent
forms, doubled delimiters, standard escapes, and the =@= no-escape prefix.
=bindingVariable= remains strictly =regularIdentifier=: quoted node and edge
bindings emit exactly =GQL-PARSE-BINDING-VARIABLE-SYNTAX=.  Malformed escapes
emit exactly =GQL-SYNTAX-INVALID-IDENTIFIER-ESCAPE= and publish no AST or IR.

#+begin_src typst
Let $S(c) := "ID_Start"(c) or "Pc"(c)$ and
$E(c) := "ID_Continue"(c)$.  Then

$ "regular"(x) "iff"
  (S(x_0) and forall i > 0: E(x_i))
  or x in N_47, $

where $N_47$ is the declaration-owned non-reserved set.  For delimiter
$d in {"double quote", "grave accent"}$,

$ "identifier"(x) "iff" "regular"(x)
  or x = d y d and "valid-escape-sequence"(y). $

Binding admission is deliberately narrower:

$ "binding-variable"(x) "iff" "regular"(x). $

Rowan preserves the source spelling and byte span; AST owns unescaping;
canonical IR folds only undelimited identities.
#+end_src

The executable contracts cover the complete non-reserved set, =U+203F=
connector punctuation, a combining =ID_Continue= mark, an alphabetic code point
outside =ID_Start=, both delimiters, doubled delimiters, Unicode escapes,
no-escape semantics, exact spans, node and edge binding rejection, and
backend-neutral canonical IR.  The wider =gql-lexical-identifiers= profile
feature remains =partial= only because unimplemented licensed-clause surfaces
outside these executable productions are not claimed.

* Lexical literal evidence

Single-quoted string literals now preserve doubled-quote escapes as one
lossless Rowan token, lower the escaped pair to one logical quote in typed AST,
and retain the exact source span while canonical IR carries the logical value.
An unterminated literal produces one declaration-owned
=GQL-SYNTAX-UNTERMINATED-STRING= diagnostic over the complete literal and no
IR.

The public OpenGQL grammar's nine exact and approximate numeric productions
are declaration-owned in Gerbil and transported through the native AOT ABI.
They cover decimal integer, common and scientific notation; exact =M= and
approximate =F=/=D= suffixes; unsuffixed scientific approximate values; and
lowercase =0x=/=0o=/=0b= integer prefixes. Optional underscores occur only
between digits. The Rust lexer executes one allocation-free ASCII scan and
emits one Rowan =Number= token. AST removes separators, normalizes =e= to =E=,
removes =M=, preserves =F=/=D= precision identity, and distinguishes exact
=Decimal= from =ApproximateNumeric=. Sema maps the latter to =Float= and both
remain backend-neutral canonical IR values.

Malformed double/trailing separators, incomplete exponents, duplicate suffixes,
uppercase radix prefixes, and trailing radix separators each produce exactly
one =GQL-SYNTAX-INVALID-NUMERIC-LITERAL= terminal and no IR. The versioned
=lexical-numerics-v1= Scenario exercises every production over 94 bytes with
zero diagnostics/fallback, a conservative measured p95 of =33.041us=, and a
316-byte observation. String backslash escapes and the remaining complete
character-sequence, byte, temporal, and duration productions remain pending;
therefore =gql-lexical-literals= remains =partial= rather than an ISO-complete
claim.

Criterion separately measures the same 94-byte fixture: lossless Rowan parsing
=8.7384--10.557us=, CST-to-AST lowering =7.3948--8.5907us=, and combined work
=15.996--20.694us=. The lowering comparison (=p=0.46=) and combined comparison
(=p=0.86=) detect no statistically significant change. Although Criterion
reported a faster parse sample, the parser implementation was unchanged
between those two samples, so this document treats that delta as environmental
variance rather than claiming a causal optimization. The implemented hot-path
improvement is structural and inspectable: integer range checks and AST integer
lowering fold digits with checked arithmetic and no separator-removal
allocation; decimal and approximate nodes allocate exactly their owned
canonical value.

** General literal value admission

The =general-literals-v1= slice admits contextual double-quoted character
strings, hexadecimal byte strings, checked calendar dates and times,
timestamps, ISO-duration-shaped values, nested lists, and ordered records.
Gerbil owns the CST shapes, literal keywords, and recovery identities;
=build.ss= stages the native declaration and the Rust projection remains
generated. Dedicated parser and AST lowering owners prevent the core parser and
lowering modules from accumulating unrelated responsibilities.

* Trivia and comment evidence

The public OpenGQL grammar derived from the ISO BNF exposes =//= and =--=
simple comments plus non-nesting =/* ... */= bracketed comments. The frontend
preserves each comment as a distinct Rowan token in source order while removing
trivia from typed AST and canonical IR. An unterminated bracketed comment emits
one declaration-owned =GQL-SYNTAX-UNTERMINATED-BLOCK-COMMENT= diagnostic over
the complete comment and admits no IR. This public compatibility evidence
expands executable coverage but does not replace licensed-clause adjudication,
so =gql-trivia-and-comments= remains =partial=.

Reference: [[https://github.com/opengql/grammar][OpenGQL ANTLR grammar]].

* Values and types evidence

Unsigned hexadecimal, octal, and binary integer literals retain their exact
=0x=, =0o=, or =0b= spelling and underscore separators in the lossless CST.
Typed AST and canonical IR normalize each accepted spelling to one integer
value without introducing backend-specific numeric authority. Invalid digits
produce one declaration-owned =GQL-SYNTAX-INVALID-NUMERIC-LITERAL= diagnostic
over the complete candidate and admit no IR. A lexically valid integer outside
the current canonical =i64= domain instead produces the distinct
=GQL-SYNTAX-NUMERIC-LITERAL-OUT-OF-RANGE= terminal; it never disappears during
AST lowering.  The Section 18 declaration value-type lattice is closed by the
recursive contracts below, while value expressions outside that declaration
boundary and licensed-clause adjudication remain pending; therefore the wider
=gql-values-and-types= profile feature remains =partial=.

* Property graph model evidence

An edge filler containing one unprefixed name is an edge binding, even when no
label constraint is present. The binding survives its exact AST span and is
canonicalized independently from the empty label set in IR. A subsequent name
requires a =:= separator; otherwise the parser emits exactly one
=GQL-PARSE-EDGE-LABEL-SEPARATOR= diagnostic at that name and admits no IR.
This closes binding/label authority ambiguity without introducing a backend
graph model. The wider property-graph feature remains =partial= pending the
remaining graph-type and catalog contracts.

* Catalog and schema evidence

=CREATE SCHEMA <name>= is a Gerbil-declared catalog entrypoint with a lossless
=CreateSchemaStatement= Rowan node. AST retains the source identifier and span;
semantic admission canonicalizes it into one backend-neutral =CatalogCommand=
without manufacturing a query IR or mutating the input catalog. When the
canonical schema identity already exists, admission emits exactly one
=GQL-SEMA-SCHEMA-ALREADY-EXISTS= diagnostic and no command. The feature remains
=partial=: conditional graph creation/removal, graph-type =COPY OF=/=LIKE=,
qualified catalog paths, and a bounded nested node-type specification are now
admitted, while graph sources, nested edge types, the remaining scalar type
surface, and live catalog mutation remain separate contracts.

** Edge-type specification admission

The public OpenGQL grammar admits both edge patterns and edge phrases.  The
current bounded slice preserves =EDGE=/=RELATIONSHIP= synonyms, optional
=DIRECTED=/=UNDIRECTED= kind, optional pattern names, named phrase fillers,
right-directed, left-directed, and undirected endpoint connectors, alias
endpoints, property-bearing inline endpoints, and empty inline endpoints.
Contextual grammar words remain identifiers outside this owner; no global
keyword table or backend authority was added.

*** Label-set and key-label filler admission

spelling: singular =LABEL=, ampersand-composed =LABELS=, =IS=, and colon.  A
key-label set retains presence independently from its labels, so textual
=IMPLIES=, symbolic ===>=, and bare implication are distinguishable from no key
contract.  The same structural nodes are used by NODE/VERTEX patterns and
phrases, EDGE/RELATIONSHIP patterns and phrases, and inline endpoint node
fillers.  Contextual words remain ordinary identifiers outside this grammar
owner.

*** Recursive declaration value types

The Section 18 declaration-type owner no longer collapses graph properties to
the runtime-inference =ValueType= enum.  Gerbil declares recursive
=PropertyValueType=, =ValueTypeAtom=, =TypeParameterList=, =FieldTypeList=,
=FieldType=, =ReferenceValueType=, and =NotNullConstraint= CST shapes.  AST
retains exact spans, source order, bounds, nested fields, nullability, and union
membership.  Canonical IR owns a separate backend-neutral
=DeclaredValueType= algebra.  This admits the scalar, temporal, LIST/ARRAY,
RECORD, dynamic-union, PATH, open and closed graph/node/edge reference, and
binding-table productions without using backend or runtime type authority.
Closed references reuse the same typed nested-graph, node-type, and edge-type
structures as catalog DDL; they are never reduced to raw source or backend
payloads.  The executable predefined matrix covers every Section 18.9
production spelling, its permitted parameter arity, and canonical synonym
family.  This closes the declaration value-type grammar boundary; it does not
claim unrelated ISO chapters are complete.

system-noisy: parsing alone moved to 141.33--189.90 microseconds although parser
code was unchanged, while lowering and combined samples reported no
statistically significant change.  The optimization is therefore admitted for
its structural correctness and lower allocation complexity; no causal speedup
is claimed until a controlled benchmark establishes one.

* ISO FILTER and FOR primitive-query admission

The =filter-for-v1= slice closes OpenGQL 14.6 and 14.8 as one primitive-query
contract.  Gerbil AOT owns =FilterStatement=, =ForStatement=, =ForItem=, and
=ForOrdinalityOrOffset= plus the exact recoveries.  Rowan preserves source
order and bytes.  AST retains the source binding, source expression, optional
=ORDINALITY|OFFSET= kind, position binding, and every span.  Canonical GQL IR
admits Boolean or unknown FILTER conditions, List or unknown FOR sources,
assigns the item binding =Any= and the position binding =Integer=, and rejects
duplicate identities without publishing partial IR.

The bounded =MetaQueryIR= adapter admits FILTER as its existing predicate
operator.  It rejects FOR by the exact name =FOR collection expansion= because
that algebra does not own an unnest operator; it does not erase the clause or
fabricate a graph binding.

#+name: rfc-0024-filter-for-admission
#+begin_src mermaid
flowchart LR
  G[Gerbil FILTER and FOR declaration] --> R[Lossless Rowan primitive query nodes]
  R --> A[AST bindings source order and spans]
  A --> I[Canonical GQL filter and for binding IR]
  R -->|malformed condition IN or WITH binding| T[Exactly one typed terminal]
  T --> Z[No statement and no IR]
  I -->|FILTER| M[MetaQueryIR predicate]
  I -->|FOR without unnest authority| F[Exact fail closed boundary]
#+end_src

#+name: rfc-0024-filter-for-logic
#+begin_src typst
Let a candidate be $c = (f, s, b, p)$, where $f$ is the FILTER value kind,
$s$ the FOR source kind, $b$ states that the item binding is unique, and $p$
states that an optional position binding is unique.  Then

$ "admit"(c) <=> f in {"Boolean", "Any"}
  and s in {"List", "Any"} and b and p. $

For an admitted candidate, the canonical bindings are

$ "type"("item") = "Any", quad "type"("position") = "Integer". $

If any syntax, type, or identity condition fails, $|"terminal"| = 1$ and
$"IR" = emptyset$.  Activation or backend identity is not part of this
frontend admission relation.
#+end_src

The frozen 108-byte Scenario records one statement, zero diagnostics, zero
fallback, 108/108 lossless bytes, 344 estimated bytes, and a
176.125-microsecond p95 against a 400-microsecond target and 5-millisecond hard
ceiling.  Criterion reports 39.298--61.130 microseconds for lossless parsing,
28.378--43.141 microseconds for CST-to-AST lowering, and 71.810--120.56
microseconds combined.  High-side outliers occurred in every sample, so this is
a baseline receipt and not a causal speedup claim.

* ISO primitive result statement admission

The =primitive-result-v1= slice closes OpenGQL 14.10 and the result-body
portion of 14.11 before SELECT reuses that authority.  Gerbil AOT owns the
=FINISH= token, =FinishStatement= shape, parser entrypoint, and recovery code.
The existing =SetQuantifier= node now also retains =RETURN ALL|DISTINCT=, while
an asterisk remains an exact lossless token rather than a fabricated
expression.  AST represents result quantifier, wildcard intent, explicit
items, and FINISH separately.  Semantic analysis expands wildcard bindings in
their first source-introduction order, retains result set semantics in
backend-neutral IR, and admits FINISH as a projection-free terminal.  A
wildcard without visible bindings and every malformed result statement fail
closed with one typed diagnostic and no IR.

#+name: rfc-0024-primitive-result-admission
#+begin_src mermaid
flowchart LR
  G[Gerbil RETURN and FINISH authority] --> R[Lossless Rowan result nodes]
  R --> A[AST quantifier wildcard items or finish]
  A --> I[Canonical result quantifier and source ordered projection]
  A --> F[Canonical projection free FINISH]
  R -->|malformed result| T[Exactly one typed terminal]
  A -->|wildcard and no visible binding| S[Typed semantic rejection]
  T --> Z[No statement and no IR]
  S --> N[No IR]
#+end_src

#+name: rfc-0024-primitive-result-logic
#+begin_src typst
Let a result candidate be $c = (k, q, B)$, where $k$ is either
$"items"$, $"all-bindings"$, or $"finish"$; $q$ is $"all"$ or
$"distinct"$; and $B = [b_1, dots, b_n]$ is the source-ordered visible
binding sequence.  Admission is

$ "admit"(c) <=> k != "all-bindings" or n > 0. $

For wildcard projection,

$ "projection"(c) = [(b_1, "type"(b_1)), dots,
  (b_n, "type"(b_n))]. $

For FINISH, $"projection"(c) = []$ and $"is-finish"(c) = "true"$.  If the
admission predicate is false, $"IR" = emptyset$; no backend or runtime
authority participates in this relation.
#+end_src

The frozen 37-byte Scenario records one statement, zero diagnostics, zero
fallback, 37/37 lossless bytes, 202 estimated bytes, and a 120.333-microsecond
p95 against a 300-microsecond target and 5-millisecond hard ceiling. Criterion
reports 33.544--55.134 microseconds for parsing, 35.243--52.343 microseconds for
CST-to-AST lowering, and 90.030--132.63 microseconds combined. High-side
outliers occurred, so these values are a baseline receipt rather than a causal
performance claim.

* Zero-fallback admission evidence

Parsing or lowering rejection now returns no =Statement=. Semantic analysis is
invoked only for an admitted statement, and an empty query returns the typed
=GQL-SEMA-EMPTY-QUERY= terminal without constructing a default query IR.
Malformed =WHERE= and =LET= forms and reserved unsupported statements each
produce exactly one diagnostic and publish neither AST statement nor IR.
Unsupported catalog shapes such as =CREATE INDEX= and =DROP INDEX= remain
typed zero-fallback terminals rather than placeholder AST variants. New catalog
surfaces are introduced only when their complete Gerbil AOT, Rowan, AST,
semantic, and canonical intent path is connected. Differential oracles remain
outside Cargo metadata, and no alias, deprecated wrapper, second parser, or compatibility
conversion preserves the removed surface.

* Failure behavior

Missing licensed clauses keep feature adjudication pending. Missing syntax,
AST, semantic, IR, catalog, or fixture evidence keeps the corresponding layer
partial or not implemented. Neither condition produces a fallback parser, a
backend-specific IR, or an implicit profile expansion.
