* Native semantic owner
:PROPERTIES:
:CUSTOM_ID: mrr-result-native-owner
:END:

MRR's =QueryResultAdmissionReceipt= is produced after typed admission of a
physical candidate against one =CatalogBoundQuery=.  It retains the binding's
query digest, generation, relation-catalog digest, entity-catalog digest and
snapshot digest, plus row count and an MRR-owned digest over ordered columns
and rows.  MRR result admission does not assert execution authenticity,
completeness or downstream causality.  Its implementation and proof scope
remain owned by the MRR repository.

The MRR-owned POO =MrrResultAdmissionProjection= records those fields with canonical
lowercase SHA-256 text encodings and a separate POO Query source hash.  The
projection digest covers all fields.  It is a *declared representation* of
native metadata: this Scheme constructor cannot prove that an MRR runtime
emitted it or that its bound query denotes the same semantics as the POO
Query.  No native Rust-to-Scheme exporter or attested crosswalk is wired yet.

#+name: mrr-result-projection-fields
#+caption: Preserved native identities and current checks.
| Native field | POO projection check | Missing verification |
|--------------+----------------------+----------------------|
| Bound-query digest | Canonical 32-byte hex representation retained | Equality to a POO Query's semantics |
| Generation | Exact nonnegative integer; matches Temporal scope | Authenticity of native generation |
| Relation and entity catalog digests | Both retained in projection digest | Catalog materialization and authority |
| Snapshot digest | Exact equality to Temporal cut digest | Snapshot bytes and coverage |
| Result digest and row count | Equal to SourceQueryReceipt assertion | Native row materialization and execution |

* Temporal handoff
:PROPERTIES:
:CUSTOM_ID: mrr-result-temporal-handoff
:END:

=mrr-projected-candidate-receipt= first replays the ordinary GQL
Query/ElementSpace/Provider receipt binding.  It then replays the MRR
projection and checks exact cut, generation, provider, result digest and row
count.  Its output uses the distinct
=mrr.query-result-admission.v1:sha256:= digest label and forces
=complete?= =#f= even when a caller's SourceQueryReceipt says complete.  A
typed MRR result-admission receipt does not by itself establish a complete
source inventory or exhaustive query answer, so an exchange remains
=pending= even if a caller supplies a =valid= CandidateCheck.  The POO Flow
scalar-row checker rejects the MRR digest label;
transcoding MRR's ordered typed rows into an unordered scalar set would lose
semantics.

#+name: mrr-result-projection-receipt
#+caption: Local evidence, not an external execution claim.
| Gate | Result | Scope |
|------+--------+-------|
| =t/mrr-query-provider-test.ss= | =MODULE-OK=, =HARNESS-OK=, =OK= | Valid projection, stale generation, wrong snapshot, forged digest, unsupported scalar checker |
| =t/temporal-candidate-exchange-test.ss= | =MODULE-OK=, =HARNESS-OK=, =OK= | Incomplete required receipt remains pending |

The native facade now exports =mrr.query-result-transport.v1= JSON under an
explicit byte limit.  It carries exact binding identities, ordered columns and
typed rows, row count and native result digest.  Its verifier checks the
version and all five binding identities against an independently supplied
=CatalogBoundQuery=, re-runs native row/type/budget admission and recomputes
the receipt digest.  Edited rows, identity, count, version, truncation and
oversized bytes fail closed in the focused Rust test.  Transport bytes alone
remain untrusted; the caller must supply the authentic bound query.  The
verified Rust value is still in-process evidence, not a cross-language call.

The remaining owner slice is a host-mediated Rust-to-Scheme handoff of that
verified value and a checked crosswalk to the original POO Query and Temporal
cut.  A Scheme caller cannot authenticate the native result by parsing this
JSON or by constructing =MrrResultAdmissionProjection= itself.  Completeness
of the physical answer also remains independent of typed result admission.
