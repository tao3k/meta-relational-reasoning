* Status

Implemented and executable.

* Decision

=mrr-frontends= is a peripheral adapter crate.  Callers select =Gql= or
=Cypher= explicitly; both adapters consume the Gerbil-projected Rowan syntax
surface, lower the supported AST slice directly, and admit only shared
=MetaQueryIr=. They do not route through a second public GQL syntax, AST,
semantic, or IR stack.

The parity slice is deliberately bounded to one =MATCH= clause containing one
or more graph path patterns, node/relationship type labels, direction,
property constraints and access, =WHERE= expressions, =RETURN= projection,
aggregates, ordering, and limit. Unsupported mutation, optional matching,
path quantifiers, union, offset, case, subscript, and unowned operators fail
before IR admission. Until the parser CST publishes precedence grouping,
mixed-precedence expressions require explicit parentheses.

Stable entity/relation type identities derive from language-neutral label
content.  Query and operator identities derive from the span-free semantic AST
projection, so source filename, whitespace, and selected frontend dialect do
not change the admitted relational intent.

* Executable equality

The focused acceptance query contains typed nodes, an outgoing typed relation,
property access in a predicate, and a projection.  Both explicit frontend
instances must return equal normalized IR and byte-identical versioned canonical
encoding.

The executable contract is
=gql_and_cypher_frontends_admit_identical_normalized_ir=. It selects each
language through =ParserLanguage=, requires distinct parser grammar digests,
then proves equal normalized values and byte-identical canonical encodings.
The V1 compilation receipt records the selected language; grammar identity is
therefore never inferred from a filename or source spelling.

The embedded runtime remains one thread-affine owner, while Rust callers and
the test harness remain concurrent. The upstream linked-program runtime fixes
Gambit processor ownership at initialization; the default parallel frontend
suite is the regression scenario and must not require =--test-threads=1= or a
caller-provided =GAMBOPT= workaround.

= RFC 0007: Frontend Parity

For the admitted common surface $S$ and semantic normalization $N$,

$ N("lower"_"GQL"(s)) = N("lower"_"Cypher"(s)) $

for every $s in S$.  Parser diagnostics or an unsupported construct produces
no partial =MetaQueryIR= value.
