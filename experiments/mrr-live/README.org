* P00 scope

P00 is a real-provider, tool-selection, and authority-boundary smoke.  It does
not claim that MRR improves accuracy.  It verifies only that a real model can
select the expected fixture, consume a real Rust-kernel receipt, and bind its
final answer to that exact receipt.  Runs are local, append-only, and ignored by
Git.

* Required next research gates

S01 Hidden Dependency and S02 Missing Premise must introduce hidden exact
oracles and matched Raw, Flat Facts, MRR, Scheme plus MRR, and Oracle MRR
conditions.  Results require repeated runs, observed cache-token accounting,
latency and token metrics, replay, and explicit failure attribution.  A live
failure may generate a hypothesis; it cannot directly change MRR semantics.
